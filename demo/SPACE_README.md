CPU traffic-video analysis API: YOLO11n, 720p decode, roughly 8 analysis fps,
one shared pass and a 120-second upload limit. This is a post-submission demo
profile, separate from the frozen YOLO11m judging pipeline. Open `/docs` for the HTTP interface.
Uploads are deleted on success/failure. Results expire after one hour or a restart.
This is a demonstration, not a road-safety decision system.
